# AgroFácil
Trabalho apresentado como TCC do curso Técnico em Desenvolvimento de Sistemas no SENAI.
Consiste em um sistema que inclui uma dashboard de controle conectada a um sistema IoT de administração de um terreno agrícola, com sensores que transmitem dados para um servidor e os apresentam na forma de insights para o usuário.
Também inclui uma seção para auxiliar pequenos agricultores da obtenção de documentos e regularização de suas operações, para que tenham acesso a benefícios do governo, como o PRONAF.
